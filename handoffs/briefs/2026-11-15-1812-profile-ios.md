## Goal
On Me, a person can edit their profile: photo (pick from library or take one; remove), name (already editable — fold it in), city ("Lives in", typed), birthday (optional). Family members see each other's photo everywhere an avatar shows, and can tap a member (Home contributions, Family settings People) to see a simple profile: big photo, name, city, their local time now (e.g. "Sydney · 9:41 pm"), birthday ("Birthday 12 March", no year shown, no reminders).

## Backend contract (a parallel worker is building it now; code against it, don't wait)
- `users:generateAvatarUploadUrl` mutation → upload URL string. POST the JPEG bytes to it with `Content-Type: image/jpeg`; response JSON `{ "storageId": "..." }`.
- `users:setAvatar({ storageId })` → null. `users:removeAvatar({})` → null.
- `users:updateProfile` gains optional `city` (string, max 40, "" clears) and `birthday` ("YYYY-MM-DD" string, or null to clear).
- `users:me` adds `photoUrl`, `city`, `birthday` (string | null each).
- Member objects from `home:familyToday`, feed actors and family member lists add `photoUrl`, `city`, `timezone` (string | null); familyToday members also `birthday`. `avatarColor` is still sent; stop using it.

## Decisions (the user's)
- Avatars are **photos only**. Remove colour from the UI entirely: with no photo, show the person's initial on one neutral fill from the existing design tokens (same for everyone). Replace every `avatarColor` use in the app with one shared avatar component (photo via AsyncImage with that neutral initial as placeholder/fallback).
- Location = a **typed city** plus **local time from their stored timezone**. No device location, no CoreLocation, no new location permission.
- Birthday optional, shown to family.
- Notes: Hugeicons for every icon (one style/stroke, currentColor), Thinking Orbs (existing `Components/OrbLoader.swift`) for upload/saving states; built for parents: large text, few screens, plain words, no red failure states.

### Libraries

- **Hugeicons** (icons): Use Hugeicons for every icon in the UI, keeping one style and stroke weight throughout and colouring with currentColor. No emoji and no hand-drawn SVG icons.
- **Thinking Orbs** (loading): Use Thinking Orbs for every AI "thinking" or loading state instead of a spinner. On web render <ThinkingOrb state="..." size={64|20} /> and pick the state that matches the activity (e.g. searching, composing). Set up: Web: `npm install thinking-orbs`; Mac: `Swift Package Manager: add https://github.com/Jakubantalik/Libraries.dev (branch main), product ThinkingOrbsKit`; iOS: `Swift Package Manager: add https://github.com/Jakubantalik/Libraries.dev (branch main), product ThinkingOrbsKit`. iOS: The page doesn't explicitly say the Swift package supports iOS or macOS, and it gives no CocoaPods option. Mac: The page doesn't explicitly say the Swift package supports macOS; SwiftUI support is implied only. Web: Requires React 18 or newer; the page lists only an npm install line.

  commits and pushes its own main (a plain fast-forward) and never leaves

  the person using the app, not which files moved.

  preview is in the handoff.
