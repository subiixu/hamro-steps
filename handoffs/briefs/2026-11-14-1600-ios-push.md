## Goal
Wire iOS push end to end against the existing `ActivityService` protocol (ios/HamroSteps/Services/ActivityService.swift: `registerDevice(apnsToken:environment:)`, `unregisterDevice(apnsToken:)`). The Convex implementation of ActivityService comes later; use whatever `AppLaunch.services()` gives today (the mock).
1. **Entitlement:** add `aps-environment: development` to the entitlements properties in ios/project.yml (Xcode switches it to production on distribution export).
2. **App delegate:** `@UIApplicationDelegateAdaptor` in HamroStepsApp.swift; `didRegisterForRemoteNotificationsWithDeviceToken` → hex token (lowercase) → `registerDevice` with `.sandbox` in DEBUG builds and `.production` otherwise. Re-register on every launch while signed in (tokens change). Remember the last token in UserDefaults for unregister.
3. **Permission:** ask for alert+sound+badge authorization once the person is signed in AND in at least one family (first time Home appears), never at cold start before sign-in. Only call `registerForRemoteNotifications` when authorized (or provisional/ephemeral).
4. **Sign-out / account switch / delete:** in SessionStore, call `unregisterDevice(lastToken)` BEFORE `auth.signOut()` and before account deletion; best effort (errors ignored, 3 s timeout), then clear the stored token. Reason: otherwise the old account's pushes keep reaching a phone that changed hands (backend review finding).
5. **Tap routing:** `UNUserNotificationCenterDelegate`. Payload `{type, familyId, eventId?}` where type ∈ walk_started, family_100, reaction, evening_nudge (docs/contract-activity.md "Notifications"). Tap → select that family on Home (and for reaction/walk_started/family_100 scroll to/highlight the feed event if Home exposes a hook; if not, just select the family). Unknown type or familyId the user isn't in → open Home unchanged. Foreground: show banner + sound.
6. Put the logic in small testable types under ios/HamroSteps/Push/ (e.g. `PushRouter` parsing payload → route, `DeviceTokenStore`), keeping the delegate glue thin.

Done = `scripts/check-ios.sh` green with new tests in ios/HamroStepsTests/Push*.swift covering: token hex formatting, environment by build, payload parsing for all 4 types + unknown + missing familyId, unregister called before signOut (mock records order), permission not requested before sign-in/family.

### Libraries

- **Hugeicons** (icons): Use Hugeicons for every icon in the UI, keeping one style and stroke weight throughout and colouring with currentColor. No emoji and no hand-drawn SVG icons.
- **Thinking Orbs** (loading): Use Thinking Orbs for every AI "thinking" or loading state instead of a spinner. On web render <ThinkingOrb state="..." size={64|20} /> and pick the state that matches the activity (e.g. searching, composing). Set up: Web: `npm install thinking-orbs`; Mac: `Swift Package Manager: add https://github.com/Jakubantalik/Libraries.dev (branch main), product ThinkingOrbsKit`; iOS: `Swift Package Manager: add https://github.com/Jakubantalik/Libraries.dev (branch main), product ThinkingOrbsKit`. iOS: The page doesn't explicitly say the Swift package supports iOS or macOS, and it gives no CocoaPods option. Mac: The page doesn't explicitly say the Swift package supports macOS; SwiftUI support is implied only. Web: Requires React 18 or newer; the page lists only an npm install line.

### Releasing

- Pushing the default branch isn't a release: each project's Jarvis
  commits and pushes its own main (a plain fast-forward) and never leaves
  the push for the user, unless the project marks main as a release
  (`gates.default_branch_is_release: true`).
- Releasing is the user's: Ultron blocks agents from tagging, force-pushing,
  deploying to production or submitting to a store. Ask the user to do it.
- Every release gets a changelog entry in the user's voice: what changed for
  the person using the app, not which files moved.
- Version numbers are semantic. A release that changes stored data bumps
  the minor version and ships a migration with a rollback note.
- Preview or staging deployments are fine without the user; say where the
  preview is in the handoff.
