- **Tables:**
  - `devices`: apnsToken (unique), userId, environment, updatedAt. `registerDevice` moves a token to the caller if another user had it.
  - `notificationPrefs`: userId, walkStarted, goalHit, reactions, eveningNudge. Defaults: true, true, true, false.
- **Mutations and queries:** `registerDevice`, `unregisterDevice`, `notificationPrefs()`, `setNotificationPrefs(partial)`.
- **Delivery:**
  - Mutations enqueue with `ctx.scheduler.runAfter(0, internal.pushNode.send, {...})` and never call the network inline.
  - `pushNode.ts` is `"use node"`. It sends over **HTTP/2** (`node:http2`) to `api.push.apple.com` / `api.sandbox.push.apple.com` per device environment.
  - Token-based auth: an ES256 JWT signed with `jose`, cached for 50 minutes.
  - Headers: `apns-topic` = env `APPLE_BUNDLE_ID` (default `com.bixustudio.hamrosteps`), `apns-push-type: alert`.
  - Reuse the existing env vars `APPLE_TEAM_ID`, `APPLE_KEY_ID` and `APPLE_PRIVATE_KEY`: the user's one .p8 key has both APNs and Sign in with Apple. When any is missing, log once and skip.
  - On 410, or a 400 with `BadDeviceToken` / `Unregistered`, delete that device.
  - Put the transport behind an interface the tests stub.
- **Who gets what:**
  - **walk_started:** every member of any of the walker's families, except the walker. Dedupe users, so one push per person even across shared families, and respect `walkStarted`.
  - **family_100:** members of that family, respecting `goalHit`.
  - **Reaction:** the event's actor, unless it's their own reaction or they muted reactions. Coalesce: at most 1 reaction push per event per 10 minutes.
  - **Evening nudge:** a cron at 19:00 Nepal (13:15 UTC). For each family under its goal, push opted-in members with supportive copy: "Your family is at 62% today. A short evening walk would help everyone get there." Never mention who is behind.
  - **Payload:** `aps.alert {title, body}`, `sound: default`, plus `{type, familyId, eventId?}`. Plain warm copy, e.g. title "Aama started a walk", body "Want to join her? Give her a call." Use the walker's name; the actual copy is "Want to join? Give them a call." (no gendered pronouns).

### Libraries

- **Hugeicons** (icons): Use Hugeicons for every icon in the UI, keeping one style and stroke weight throughout and colouring with currentColor. No emoji and no hand-drawn SVG icons.
- **Thinking Orbs** (loading): Use Thinking Orbs for every AI "thinking" or loading state instead of a spinner. On web render <ThinkingOrb state="..." size={64|20} /> and pick the state that matches the activity (e.g. searching, composing). ### Releasing

- Pushing the default branch isn't a release: each project's Jarvis
  commits and pushes its own main (a plain fast-forward) and never leaves
  the push for the user, unless the project marks main as a release
  (`gates.default_branch_is_release: true`).
- Releasing is the user's: Ultron blocks agents from tagging, force-pushing,
  deploying to production or submitting to a store. Ask the user to do it.
- Every release gets a changelog entry in the user's voice: what changed for
  the person using the app, not which files moved.
- Version numbers are semantic. A release that changes stored data bumps
  the minor version and ships a migration with a rollback note.
- Preview or staging deployments are fine without the user; say where the
  preview is in the handoff.
